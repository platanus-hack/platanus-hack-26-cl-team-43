¿Cachai qué modelo te están sirviendo?

El modelo que evaluaste y el que te responde pueden no ser el mismo. Cachai audita desde afuera cada endpoint y marca los que se apartan de la referencia.

Lo evaluado y lo desplegado dejan de ser lo mismo. Si el endpoint sirve otro modelo, una versión degradada o un prompt agregado, las evaluaciones y las salvaguardas del modelo original ya no cubren lo que está en producción.

Un prompt oculto es un ataque a la cadena de suministro. El proveedor que agrega instrucciones propias delante del pedido cambia el comportamiento del modelo sin que nadie lo vea. SOC 2 e ISO 27001 revisan procesos de la empresa y no cubren nada de esto.

Verificar las características declaradas de un modelo sin tener acceso a él es un problema abierto de gobernanza técnica de IA (Reuel, Bucknall et al., 2024, sección 5.4.1).

Una ficha por corrida, con lo declarado y lo medido.

cachai scan le manda el mismo juego de pruebas a cada endpoint y a una referencia. Cada dato de la ficha dice si lo declara el proveedor (E1) o si se midió desde afuera (E2). Los controles son deterministas, sin juez LLM: la respuesta auditada no puede inyectar al auditor y la ficha da el mismo veredicto cada vez.

Tokens de prompt de sobra E2

Compara los tokens de prompt de mensajes mínimos contra la referencia. Un excedente constante es la firma de un prompt oculto.

Exactitud y coincidencia E2

Tareas con respuesta calculable y frases de texto libre, a temperatura 0. La coincidencia con la referencia se compara con la de la propia referencia en otra llamada (el piso de ruido). Así se ve una cuantización que acierta igual pero responde distinto.

Tool calls válidas E2

Una herramienta con esquema estricto. Cuenta cuántas llamadas lo cumplen.

Secreto del system prompt E2

Un canario en el system prompt y un juez determinista miden si el endpoint lo filtra cuando se lo piden. En la demo, el prompt oculto del tramposo lo hace filtrarlo 8 de 8 veces.

Confiabilidad E2

Errores y latencia mediana de cada endpoint durante la corrida.

Lo declarado E1

Cuantización y precio, tal como los publica cada proveedor en la API de OpenRouter.

Pruebas que el proveedor no puede reconocer.

Un sistema que distingue la evaluación del uso real puede portarse bien solo cuando lo evalúan. Por eso el juego de pruebas se genera con una semilla nueva en cada auditoría. La semilla queda en la ficha junto con el SHA-256 de las respuestas crudas, para que cualquiera pueda repetir la misma auditoría.

El auditor se mide contra un proveedor tramposo propio: un proxy que agrega un prompt oculto, desvía parte del tráfico a un modelo más barato y se porta bien cuando reconoce un benchmark conocido. Nunca se ataca a terceros.

Cómo se usa.

# sin claves y en 10 segundos: un proveedor honesto y dos tramposos de juguete
uv tool install git+https://github.com/platanus-hack/platanus-hack-26-cl-team-43
cachai demo
# sin clave: qué declara cada proveedor (cuantización y precio)
cachai endpoints z-ai/glm-5.3
# los 6 más baratos contra el del autor; necesita OPENROUTER_API_KEY
cachai scan z-ai/glm-5.3 --providers 6 --max-usd 2
# la ficha queda en audit/fichas/ (JSON, Markdown y respuestas crudas con su SHA-256)
# el primero es la referencia; cada clave se lee de su variable (DEEPSEEK_API_KEY, TOGETHER_API_KEY…)
cachai scan -e deepseek:deepseek-chat -e together:deepseek-ai/DeepSeek-V3
# tu propio servidor o cualquier API compatible con OpenAI
cachai scan -e ollama:qwen2.5:7b -e prod=https://mi-gateway/v1,PROD_API_KEY,qwen2.5-7b
# cachai.toml en tu carpeta, y después solo: cachai scan
openrouter = false
max_usd = 1

[[endpoint]]
provider = "deepseek"        # la referencia
model = "deepseek-chat"

[[endpoint]]
provider = "together"
model = "deepseek-ai/DeepSeek-V3"
# sin claves, unos 2 minutos: benchmark fijo contra juego ciego, con el proveedor tramposo
git clone https://github.com/platanus-hack/platanus-hack-26-cl-team-43 cachai && cd cachai
uv run cachai experimento --toy --reps 30

Funciona donde funcione la API de OpenAI.

Cachai usa la misma API que cualquier cliente. No pide acceso al modelo ni que el proveedor colabore, así que sirve para cualquier endpoint compatible con OpenAI.

OpenRouter

Lee los endpoints de un modelo, fija cada proveedor sin fallback y los compara con el del autor. cachai scan z-ai/glm-5.3

Proveedores de inferencia

Atajos para Together, Fireworks, DeepInfra, Groq, Cerebras, SambaNova, Novita, Hyperbolic y Nebius. -e together:MODELO

La API del autor

DeepSeek, Moonshot (Kimi), Z.ai (GLM) y Mistral, la mejor referencia contra la que comparar. -e deepseek:deepseek-chat

Tus servidores

Ollama, vLLM, SGLang, LM Studio y llama.cpp: comprobá que una cuantización o una plantilla nueva no cambió el comportamiento. -e ollama:qwen2.5:7b

Cualquier otra API

Un gateway interno o el proveedor que ya contrataste, con su URL y el nombre de la variable de la clave. -e prod=URL,VAR,MODELO

Tu CI

Una auditoría semanal en GitHub Actions que falla si un endpoint se vuelve distinguible de la referencia. --strict

Hoy el código cubre E1 y E2.

Para quién. Equipos con agentes en producción sobre modelos abiertos servidos por terceros. Lo usa quien responde por lo que hacen esos agentes, para saber si un endpoint se aparta del modelo que evaluó y sacarlo del tráfico.

Independiente del auditado. La auditoría corre del lado de quien usa el modelo y no la financia quien lo sirve. Con la semilla y el SHA-256 de las respuestas, un tercero puede repetirla.

Qué no promete.

«Sin desviación detectada» no significa «es el mismo modelo». Cada dato de la ficha dice si está declarado por el proveedor o medido desde afuera.
No certifica privacidad. Desde afuera no se puede probar que un proveedor no mire ni guarde los datos.
«Distinguible de la referencia» no es una acusación. Puede deberse a la plantilla, al parser o a la cuantización.
La referencia también es un endpoint. Si está cuantizada, se mide equivalencia con ella, no con el modelo original.
Un proveedor que estudie el generador de pruebas puede evadirlo. Está medido: 0 de 30 en todas las trampas. El paso siguiente es auditar con una muestra del tráfico real.
